# 个性化配置（个人专属 skill）

本 skill 是个人专属排版引擎，下列"人格化"配置在此集中管理，排版时读取本文件取值。
改这里即可全局改变署名 / 落款 / 头像 / 语气，**不用动主题组件库**。

## 署名 / 落款（默认值，可在请求里临时覆盖）

```
作者名：      甲木            # 引言卡右下署名、签名区"我是 XX"
一句话简介：  热衷于分享 AI 观察与团队协作干货
互动引导文案：如果你觉得今天这篇有收获，欢迎「点赞、在看、转发」三连，我们下篇见
```

> 用户在请求里给了署名/简介就直接用；没给就用上面的默认值。`{{作者名}}`/`{{简介}}` 占位符在装配时替换成这里的值，**不要再保留占位符**。

## 猫 IP（个人标识，可选装饰）

用户有一只**戴红针织帽、穿蓝羽绒**的猫作为个人 IP（红帽≈主橙、蓝衣≈辅助蓝，天然贴合本主题配色）。
本地源图：`assets/cat-ip.png`。

**关键约束**：公众号编辑器只吃**外链图片 URL**（`http(s)`），本地 `assets/cat-ip.png` 不能直接写进 `<img>`。
- 用户提供了猫图的外链 URL → 直接填入下面组件的 `{{猫图URL}}`。
- 用户没提供外链 → **不要**用本地路径硬塞（会破图），交付时提示用户：把 `cat-ip.png` 上传到任意图床/公众号素材库，把链接给我，我再加进去。

### IP 出现位置（克制，只放尾部签名区，别到处贴）

| 位置 | 用法 | 组件 |
|------|------|------|
| 尾部签名区（作者卡左侧） | 圆形头像（~62px）+ 名字/简介竖排 + CTA | 组件 16b 签名区·IP 作者卡版 |

原则：**开头引言卡不放头像**（保持引言卡干净）；猫头像只出现在尾部签名区一次；头像统一处理成圆形、白描边 + 橙外圈，与主题圆角语言一致。
